📥 받은 문서 처리할 때 — 문서 먼저 붙여넣고

올라온 문서 빨리 파악위 문서를 3줄로 요약하고, 결재 전에 확인해야 할 질문 3가지를 뽑아줘.
내 계획서 셀프 검토 — 결재 올리기 전에위 계획서의 약한 부분을 상급자 관점에서 지적해줘. 예산, 일정, 리스크 순서로.
회의록 → 할 일 목록위 회의 내용에서 ①결정된 것 ②해야 할 일(담당자별) ③다음 회의까지 확인할 것으로 나눠서 정리해줘.
어려운 지침·공고문 번역위 내용을 처음 보는 주민도 이해할 수 있게 쉬운 말로 다시 써줘. 전문용어는 일상어로 바꿔줘.

📋 양식대로 쓰기 — 실무 사용 빈도 1위

작년 문서·기존 양식에 새 내용만 갈아 끼우는 법. 양식과 내용을 나눠서 주는 게 핵심입니다.

기존 양식에 새 내용 채우기 — 기본형아래 [양식]의 구조, 항목, 어투를 그대로 유지하면서 [새 내용]으로 다시 작성해줘. 양식의 틀은 절대 바꾸지 말고 내용만 교체해줘. [양식] (기존 문서) [새 내용] (이번 내용)
새 내용이 아직 없을 때 — 뼈대만 갈이아래 문서의 구조는 그대로 유지하고, 내용을 (이번 사업명) 기준으로 바꿔줘. 아직 확정 안 된 수치는 00으로 비워둬. (기존 문서 붙여넣기)
연차 문서 업데이트 — 작년 것 올해 버전으로아래 작년 문서를 올해 버전으로 업데이트해줘. 바뀐 것만 알려줄게: (변경사항 나열). 나머지는 그대로 두고, 바꾼 부분에는 표시해줘. (작년 문서 붙여넣기)

💡 "어투 유지"를 꼭 넣으세요 — 공문서는 개조식 말투(~함, ~임)까지가 양식입니다. "틀은 절대 바꾸지 말고"는 AI가 멋대로 항목을 합치는 걸 막아줍니다.

✍️ 문서 만들 때

결과보고 — 오늘 배운 그것아래 내용으로 결과보고 개요를 만들어줘. 구조는 사업개요 → 추진실적(표) → 예산집행(표) → 성과 및 개선점 → 향후계획. (내용 붙여넣기)
행사·교육 계획안 뼈대(행사명) 계획안 초안을 표 중심으로 만들어줘. 항목: 행사명 / 목적 / 일시 / 장소 / 대상 / 주요 내용 / 소요예산 항목 / 추진 일정. 수치는 00으로 비워두고 내가 채울게.
인사말씀·축사 — 매번 새로 쓰기 힘든 그것(행사명) 개회식에서 할 기관장 인사말씀을 2분 분량으로 써줘. 참석자는 주민과 유관기관 관계자. 계절 인사로 시작하고, 따뜻하되 격식 있게.
민원 답변 — 감정 소모 줄이기아래 민원에 대한 답변 초안을 써줘. 공감 표현으로 시작하고, 해드릴 수 있는 것과 어려운 것을 구분해서, 정중하지만 명확하게. (민원 내용 붙여넣기)
주민 안내문아래 사업 내용을 주민 안내문으로 바꿔줘. 어르신도 이해할 쉬운 문장으로, 누가 / 언제 / 어디서 / 어떻게 순서로. (내용 붙여넣기)

🎁 알아두면 좋은 마법 문장

아무 AI에서나 감마용 변환 (도우미 없이도)위 개요를 감마(Gamma)에 붙여넣을 형태로 바꿔줘. 슬라이드 1장은 제목 1줄과 내용 3~5줄, 수치는 '항목: 수치' 목록으로.
한글로 가져가기지금까지 내용을 한글 문서에 붙여넣을 표로 바꿔줘.
뭐라고 시켜야 할지 모를 때 — 최강의 한 수내가 뭘 알려주면 되는지 먼저 물어봐줘. 질문은 한 번에 2개까지만.
